# 中国象棋

> 象棋引擎来自象棋小巫师的原始 js 代码， 并新增了**联机双人对战**模块。

## 🌟 新增功能：双人联机对战

项目引入了 Rust 编写的高性能后端，支持玩家通过 WebSocket 进行实时联机对局。

### 核心特性

- 🔗 **房间分享**：支持一键生成并复制专属房间链接，快速邀请好友加入或作为观众旁观对局。
- ⚔️ **相互同意机制**：悔棋、重开均需要经过对方玩家弹窗同意，确保对战公平与交互友好。
- 🛡️ **安全防作弊**：
  - 所有棋子的移动轨迹、几何合法性与盘面障碍（如蹩马腿、塞象眼、炮架）全部由 Rust 后端进行实时校验与权威判定。
  - 杜绝客户端伪造 FEN 局面，保障联机对局的公正性。
  - 详见设计文档：[anti_cheat_design.md](file:///Users/chen/src/github.com/zuisong/chiness-chess-web/design/anti_cheat_design.md)。
- 💬 **内置聊天**：对局双方及旁观者可在房间内进行实时文字沟通。
- ♻️ **自动垃圾回收**：当对局玩家与旁观者全部断开连接后，后端会自动销毁该房间，避免常驻内存导致溢出。

## 🛠️ 本地运行与构建

项目使用 [go-task](https://taskfile.dev/) 统一管理前端与后端的开发、检查与构建任务。

### 常用命令

- **启动开发服务器**（前端+后端）：
  ```bash
  task dev
  ```
- **一键运行测试与类型/代码风格检查**：
  ```bash
  task check
  task test
  ```
- **项目构建**：
  ```bash
  task build
  ```
